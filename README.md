# Калькулятор матриц комплексных чисел (Java)

Практическая работа №1: реализация объектно-ориентированной библиотеки для работы с матрицами комплексных чисел и интерактивного консольного интерфейса (CLI).

## Функциональные возможности

Проект поддерживает работу с матрицами произвольной размерности, элементы которых представлены комплексными числами в алгебраической форме ($z = a + bi$):

* **Сложение матриц ($A + B$):** поэлементное сложение матриц одинаковой размерности ($m \times n$).
* **Умножение матриц ($A \cdot B$):** перемножение согласованных матриц размерности $m \times n$ и $n \times k$.
* **Деление матриц ($A / B$):** умножение матрицы $A$ на обратную матрицу $B^{-1}$ ($A \cdot B^{-1}$). Выполняется проверка квадратности делителя и невырожденности ($\det(B) \neq 0$).
* **Транспонирование ($A^T$):** замена строк матрицы на её столбцы с изменением размерности с $m \times n$ на $n \times m$.
* **Вычисление определителя ($\det A$):** рекурсивное нахождение детерминанта квадратной матрицы методом разложения по первой строке (через миноры и алгебраические дополнения).
* **Обработка исключений:** перехват математических и размерностных ошибок через собственный класс исключений `MatrixException` и защита от некорректного пользовательского ввода в консоли.

## Структура проекта

Все классы находятся в пакете `matrix`:

```text
src/
├── exception/
│   └── MatrixException.java
└── matrix/
    ├── Complex.java
    ├── Matrix.java
    └── Main.java       # Консольный интерфейс пользователя (CLI)
```

### Описание классов

| Класс | Назначение и ключевые методы |
| :--- | :--- |
| **`Complex`** | Представляет комплексное число ($Re, Im$). Содержит методы `add()`, `subtract()`, `multiply()`, `divide()`, `scale()`, проверку на ноль `isZero()` и форматированный вывод `toString()`. |
| **`Matrix`** | Хранит двумерный массив `Complex[][]`. Реализует статические методы `sum()`, `multiply()`, `divide()` и методы экземпляра `transpose()`, `determinant()`, `inverse()`, `print()`, `checkSquare()`. |
| **`MatrixException`** | Наследуется от `Exception`. Генерируется при несовпадении размерностей матриц, попытке деления на вырожденную матрицу ($\det = 0$) или выходе за границы индексов. |
| **`Main`** | Точка входа в программу. Реализует бесконечный цикл меню, чтение матриц из стандартного потока ввода (`Scanner`) и валидацию вводимых токенов. |
